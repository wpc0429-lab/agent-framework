# PX-Work 企业人工智能统一控制平面宣贯页

本包包含会议宣贯页面的完整源码与已构建的静态发布文件。

## 直接部署

将 `dist/client/` 目录下的全部文件复制到企业内网 Web 服务器即可。

页面为纯前端静态站点，无需后端服务或外网依赖。若 Web 服务器启用了单页应用路由回退，可将未知路径回退至 `index.html`。

## 本地预览与修改

1. 安装 Node.js 18 或更高版本。
2. 在本目录执行 `npm install`。
3. 执行 `npm run dev` 进行本地预览。
4. 修改完成后执行 `npm run build`，发布新的 `dist/client/` 目录。

## 目录说明

- `src/`：页面内容与样式源码。
- `public/assets/`：宣贯架构图原始视觉资产。
- `dist/client/`：已构建、可直接部署的静态页面。
- `design-qa.md`：交互和视觉核对记录。
